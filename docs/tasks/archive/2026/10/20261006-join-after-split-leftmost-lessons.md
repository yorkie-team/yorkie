# Lessons: Join paragraphs right after an Enter in the middle of a span

**Created**: 2026-10-06

- A port that drops a guard leaves a test suite that agrees with itself. The
  surrogate test's expected tree came from Go's own output and went through
  the dropped merge; nobody had compared it with JS. When a test pins a
  shape built by concurrent or structural edits, run the same steps on the
  other SDK once.
- Found by a self-review of yorkie-js-sdk#1408 (yorkie#2143) that compared Go
  and JS outputs over random races.
